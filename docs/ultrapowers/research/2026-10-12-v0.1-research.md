## Decisiones que salen de la investigación

| Tema | Decisión | Por qué |
|---|---|---|
| Next.js | **16.4.x** (última estable; React 19.3). Aplicar el parche de seguridad del **2026-10-14** en cuanto salga | Menor dentro de 16, sin rotura frente al 16.2 de los hermanos |
| Cache Components | **Apagado** en la v0.1 (`create-next-app` 16.4 lo prende por defecto) | Todo es por usuario y dinámico; los hermanos no lo usan y así el código se copia sin traducir. Se reevalúa antes de Next 17 |
| Gestor de paquetes | **npm** | Lo que usan `CLAUDE.md` y los hermanos |
| Middleware | **`proxy.ts`** con `export function proxy()` (Node) | `middleware.ts` está deprecado en 16 |
| UI | `shadcn init -b base` (Base UI, como los hermanos) · Tailwind 4.3 · **solo oscuro**: la paleta «Klo-Ser Noche» va directo en `:root`, sin bloque `.dark` ni `next-themes`, `color-scheme: dark` | |
| Supabase clientes | `@supabase/ssr` 0.12 + `supabase-js` 2.117 · llaves nuevas `sb_publishable_…` / `sb_secret_…` · autorización con **`getClaims()`**; sesión refrescada **solo** en `proxy.ts` | Las llaves anon/service_role se deprecan a fin de 2026; refrescar en dos lados cierra sesión |
| **Grants explícitos** | Cada tabla nueva lleva `grant select, insert, update, delete … to authenticated` además de RLS | Cambio de Supabase: desde 2026-10-30 las tablas de `public` ya no se exponen solas a la API |
| Lista permitida | Hook **Before User Created** como función Postgres que lee `private.correos_permitidos` (reemplaza la variable `CORREOS_PERMITIDOS` del spec) | Corre antes de crear el usuario y cubre OAuth |
| Google: entrar vs. Calendar | **Flujos separados.** Entrar = Supabase Auth con Google (perfil). Calendar = OAuth propio en Ajustes con `access_type=offline`, `prompt=consent`, `include_granted_scopes=true` | Entrar queda ligero; Calendar se conecta/revoca aparte; Supabase no guarda ni refresca tokens de proveedor |
| Permiso de Calendar | `calendar.readonly` | Cubre listar calendarios y leer eventos |
| Consentimiento OAuth | **Publicar «En producción» sin verificar** (pantalla de aviso; tope 100 usuarios) | En «Prueba» el refresh token caduca a los **7 días** |
| Token de Google | AES-256-GCM en la app (IV de 12 bytes por registro, `key_version`), en tabla del esquema **`private`** que solo lee el servidor con la llave secreta | Vault es para pocos secretos de proyecto, no tokens por usuario |
| Sincronización | `googleapis` (o `@googleapis/calendar`) + `OAuth2Client` · primera pasada con `timeMin/timeMax` + `singleEvents=true`; `nextSyncToken` solo en la última página · incremental con `syncToken` (sin timeMin/timeMax/orderBy/q) · **410** → borrar eventos de ese calendario y resincronizar · `invalid_grant` → `estado='revocada'` | Guía oficial de sync |
| Pasada cada 15 min | **pg_cron + pg_net** → `POST /api/google/sincronizar` con `Authorization: Bearer CRON_SECRET` (URL y secreto en Vault); endpoint idempotente | Vercel Hobby solo permite cron diario. En localhost: solo «al abrir» |
| Klo | **`claude-haiku-5-5`** · `client.messages.parse()` con `output_config: { format: zodOutputFormat(esquema), effort: 'low' }` · `timeout` ~3.5 s y `maxRetries: 1` (cabe en los 8 s) · sin `temperature`/`top_p`/prefill (dan 400) · leer bloques por tipo · `max_tokens` 2048 · prompt de sistema estático con `cache_control` (mín. 512 tokens), la fecha va en el turno del usuario | ~US$0.0003 por captura. El SDK no impone `maxItems` → validar 1..5 en `esquema.ts` (ya previsto) |
| PWA | `app/manifest.ts` con `start_url: '/hoy'`, `id`, `display: 'standalone'` · `apple-touch-icon` 180 · `metadata.appleWebApp` + `viewport.themeColor` + `viewport-fit=cover` y `env(safe-area-inset-*)` · service worker con **`@serwist/turbopack`** y página `/~offline` · `navigator.storage.persist()` | Guía oficial de Next 16.4 |
| iOS | Sin `shortcuts` ni `share_target` en el manifest (no los soporta) · el foco programático no abre el teclado (ya previsto: campo visible, a un toque) · el almacenamiento de la app instalada no se comparte con Safari | |
| Pruebas | **Vitest 5** (jsdom, `vite-tsconfig-paths`) para lo puro · **pgTAP** con `basejump-supabase_test_helpers` vía `supabase test db` para RLS · **Playwright 1.64** con `devices['iPhone 14']` (390 px) y escritorio 1440 | Los Server Components async no se prueban en unidad: van por Playwright |

## Detalles de implementación que el plan debe recoger

- `create-next-app@16.4.x … --ts --tailwind --eslint --app --src-dir --import-alias "@/*" --use-npm --yes`
  sin Cache Components; luego leer `node_modules/next/dist/docs/` (regla de `CLAUDE.md`).
- `next lint` ya no existe: ESLint 9 con config plana (`eslint-config-next@16`). Script `lint` = `eslint .`.
- APIs de petición solo async (`await cookies()`, `await params`).
- RLS:
  - `private.es_miembro` es `security definer`, con `set search_path = ''` y `(select auth.uid())`. Se le quita `execute` a `public`/`anon` y se le da a `authenticated`, más `usage` en `private`.
  - Las policies llevan siempre `to authenticated`. Las de UPDATE llevan `using` y `with check`, y necesitan su policy de SELECT.
  - Índices en `miembros(user_id, espacio_id)` y en el `espacio_id` de cada tabla.
- Crear un espacio va por el RPC `crear_espacio()` (`security definer`), nunca por `insert().select()`. Si no, da el error 42501 por la policy de lectura.
- El callback de Supabase va en `app/auth/callback/route.ts` (`exchangeCodeForSession`, solo acepta `next` relativo). El de Calendar va en `app/api/google/callback`.
- `cron.job_run_details` crece sin límite: hay que programar su limpieza.
- El esquema de Klo usa `additionalProperties: false`, `enum` para `clase` y campos nulos-pero-requeridos. El primer uso compila el esquema; conviene calentarlo.

## Decisión pendiente (para Jair)

**¿Supabase local con Docker o directo al proyecto DEV en la nube?** Las pruebas de RLS y el
desarrollo cómodo piden Supabase local, que necesita **Docker Desktop** (WSL2). Alternativa:
trabajar contra el proyecto **DEV** en la nube (`supabase db push`, pruebas pgTAP con
`--db-url`), sin instalar nada, a cambio de que cada migración toque la nube.
